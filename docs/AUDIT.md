# 全链路审计记录

v0.4.5 / build 21，2026-11-06。工作区起点为干净 main（v0.4.4 / build 20 已发），原基线 129 项测试 / 670 次断言通过。本轮由用户实机反馈驱动：菜单栏图标悬停提示（如“声音守卫：音量为 0，等待新的播放活动”）经常跟着光标跑很远。

## 实机证据与根因

`updateStatus` 在每次 `onUpdate` 时对 `status.button.toolTip` 无条件赋值；触发源包括 30 秒心跳、系统音频事件回调与恢复确认计时。零音量守望（v0.4.4）使该状态长期驻留，悬停窗口与刷新相交概率大增。AppKit 属性式 toolTip 的赋值会移除并重挂帮助标签注册；发生在标签显示中时，标签失去“鼠标离开即消失”的归属并跟随光标移动，直到下一次鼠标进出事件。

## 范围与结果

| 链路 | 审查与处理 |
| --- | --- |
| 提示注册 | StatusTooltipProvider 于启动时 addToolTip 注册一次，运行期不再赋值属性式 toolTip |
| 提示内容 | 显示时回调实时读取“声音守卫：+stateText”，不缓存启动快照 |
| 无障碍 | updateStatus 改为 setAccessibilityHelp，AXHelp 随状态同步且不经过标签管理器 |
| UI 自检 | 新增：属性式提示未安装、回调文本正确、AXHelp 同步、重复刷新不回退；自检结束移除状态栏项 |
| 行为边界 | 保护、恢复、守望、诊断、偏好、权限与全部文案零变化 |
| 文档 → 版本 | 同步 0.4.5 / build 21 全套入口；构建与安装分离 |

## 保留边界

- 显示中提示不原地换字为系统原生行为取舍：移开再悬停即见最新状态。
- 帮助标签注册 rect 取按钮 bounds；NSStatusItem.squareLength 固定方形，正常使用宽度稳定。
- 悬停跨心跳/音频事件 ≥ 30 秒的实机复现验收未自动执行（A30），不因机制修复宣称实机复测通过。
- 本地构建、安装、Git 提交、远端 CI 和公开 Release 是独立交付门禁，不相互推导；无 Developer ID/公证。
