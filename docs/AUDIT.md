# 全链路审计记录

v0.4.2 / build 18，2026-10-25。工作区起点为干净 main，原基线 107 项测试 / 513 次断言通过。

## 范围与结果

| 链路 | 审查与处理 |
| --- | --- |
| 设置 → 策略 → 截止任务 | 默认值、迁移、名单、完整空闲期、旧任务失效保持回归 |
| 截止任务 → HAL 归零 | 修复写前安全取消误锁定；读取、取消与实际写入故障分离 |
| 归零 → 恢复监听 → 确认 | 失效记录立即释放监听，写前临时错误保留资格，真实写入错误仍锁定 |
| 故障 → 退避 → 健康预算 | 修复无通知的健康时段和例外播放分支，停止再启动清理检测故障 |
| Signal Tap → C 摘要 → 健康判断 | 修复有声后无效样本遗漏；格式、静音、启动和过期样本继续回归 |
| 播放进程 → 身份 → 例外 | 父路径限 `.app`，嵌套、相似路径、helper、混合和未知来源保持回归 |
| UI → 控制器 | 冷却期间归零禁用，统一选择弹窗品牌；UI 自测隔离正式偏好 |
| 状态 → 诊断 | 保留最近故障、有界 64 条/0600；不新增音频、设备身份和播放 App 日志 |
| 源码 → App → ZIP → CI | 干净暂存构建、版本门禁、写前归档防覆盖、ZIP 完整性与版本校验和 |
| 文档 → 版本 → 安装 | 修复关于页旧版本、PRD 多个当前版本及测试历史口径；安装与构建明确分离 |

## 保留边界

- Core Audio 同步 API 曾在历史 Tap 探针阻塞；本轮未伪造系统级超时修复，主线程阻塞风险仍存在。
- 真实 MuMu、播放器、多通道、蓝牙/USB/HDMI、睡眠、权限允许/拒绝、多屏/Space、VoiceOver 和登录项未完成全矩阵。
- 完整 App 的各状态 10 分钟和 8 小时性能仍未验收；完整缓冲区扫描的开销不能沿用旧性能数据。
- 初轮审计未替换运行中 App；随后用户明确要求安装，已备份并安装，偏好、启动版本、签名与二进制一致性通过。未自动调高音量、重启音频服务或修改权限。
- 本地构建、安装、Git 提交、推送、远端 CI 和公开 Release 是独立交付门禁，不相互推导。
