# 使用指南

打开 Sound Guard.app 后点击菜单栏盾牌声波图标。默认保护内建扬声器，默认空闲 5 分钟归零。应用不会自行调高音量；恢复提醒默认关闭，开启后也只有点击提示中的恢复按钮才会调高。

## 两种检测模式

默认模式：音量大于 0 时监听系统输出播放活动；没有播放连续达到设定时长归零。播放器持续输出全零静音流也被当作播放，不会误关。

“静音流也计时”：在设置主动开启，额外检查数字音频。连续全零也会计时；微弱但非零声音不计为静音。需要 macOS 系统音频录制访问（具体权限名称随系统版本变化），不是麦克风权限，不保存录音。检测异常会停止保护并提示“重新核对”，不会偷偷退化为检测成功。

恢复提醒关闭时，音量 0 或系统静音会停止两种空闲检测，只保留音量、路由与设备变更事件。恢复提醒开启且由本 App 自动归零后，默认模式保留播放进程事件监听；“静音流也计时”模式复用已有 Signal Tap，以真实非零信号而不是静音进程状态触发提示。

## 设备

内建扬声器默认勾选。耳机、蓝牙音箱、USB、显示器输出等默认不勾选，在“设置与设备选择”中选择。只对当前系统默认输出生效，既不切换输出，也不修改其他闲置设备。

设备按 UID 和路由保存，不靠同名推断。同名新设备、有线耳机插孔、路由变化可能需要重新选择。离线记录保留，取消勾选可移除。设备列表是设置窗口打开/刷新时的快照；插拔后可点击刷新。无法调节音量的设备明确标记不支持。

## 计时与操作

1. 设置 1–120 分钟整数后点击应用，当前空闲时间从头计算。
2. 播放开始、手动调节音量、切换设备、唤醒、恢复保护均取消旧计时。
3. “立即归零”只针对受保护的当前设备，即使在播放也可执行。
4. “暂停保护”不改动现有音量；退出也不恢复或修改音量。
5. 异常后点击“重新核对”。App 会先释放当前音频检测，显示“正在重新核对”，等待 3 秒后只重建一次；期间不能重复点击，也不会执行自动归零。成功后自动恢复正常计时；若仍提示异常，请检查系统音频录制访问，或关闭“静音流也计时”回到默认模式。

## 播放恢复提醒

“播放时提示恢复”默认关闭。打开设置中的开关时，App 先说明新增监听和权限用途；确认后才请求辅助功能权限。功能关闭时不申请此权限。辅助功能只用于寻找播放 App 的活动窗口和对应显示器，不参与音频判断；拒绝后提示仍可使用，但显示在鼠标所在屏幕。

此功能只对声音守卫因空闲超时完成的自动归零生效。归零成功后，原设备、稳定 UID/路由、静音状态和各音量通道原值只保存在内存。菜单“立即归零”、系统音量键归零和其他 App 改成 0 都不建立恢复凭据。

“有声确认”控制播放活动需要持续多久才显示恢复提示，默认 2 秒，可设置 500 毫秒至 30 秒。默认模式要求目标输出进程持续活跃；“静音流也计时”模式要求系统输出信号持续判定为有声。确认期间停止播放会取消本次候选，下次播放重新计时；严格模式不足 600 毫秒的短暂停顿仍视为连续播放。该参数只控制弹窗出现前的确认，不改变空闲归零时长，也不改变弹窗自身停留时间。

检测到新的播放活动后，目标显示器右上角出现不抢焦点且无提示音的窗口。默认显示 60 秒，可设置 5–600 秒，也可用分钟输入。点击“恢复音量到 …%”前会再次核对当前默认设备、路由、静音和音量仍为 0；点击“保持静音，不再提醒”会保持 0、消费本次自动归零的恢复凭据并释放恢复监听。按钮不绑定 Return，避免误操作。

同一段连续播放只提示一次。左上角关闭或倒计时结束只临时收起，保持音量 0；需先停止播放，再开始下一段播放并重新满足有声确认时长才会再次提示。点击任一底部按钮都完成本次选择，不再提示；严格模式使用 600 ms 防抖，短于此时长的无声间隔仍视为同一段播放。恢复、明确保持静音、用户手动改音量、切换设备、切换检测模式、睡眠、关闭自动保护、关闭恢复提醒、移除当前保护设备或退出 App 都会使旧请求失效。恢复的是系统输出设备音量，其他同时播放的 App 也可能出声。

播放进程若是浏览器或媒体辅助进程，App 会尽量映射到外层应用；多个窗口、后台播放、跨 Space 或驱动未提供 PID 时不能保证命中真正播放内容的窗口，届时回退到鼠标所在显示器。

“登录时启动”默认关闭，仅你启用后注册；需要批准时到系统设置的登录项处理。

## 限制

不同软件可自行调大系统音量，本工具不是绝对防出声安全边界。默认模式和恢复提醒依赖软件是否报告输出 IO；严格模式依赖系统真实音频回调，驱动异常产生的全零可能与真静音不可区分。重要场合请自己确认系统静音。

macOS 声音效果可能使用单独输出路由，首版不控制独立的系统声音效果输出或应用自选的非默认设备。Intel 和低版本系统包含构建支持但未等同实机验证。更多见 [测试](TESTING.md) 与 [性能](PERFORMANCE.md)。

## v0.2.0 界面导航

菜单顶部展示保护状态与当前设备；下方提供自动保护、立即归零、常用等待时长、静音流选项和设备入口。设置快捷键为 Command+,，退出为 Command+Q。菜单内容在打开时刷新，不增加倒计时刷新器。

设置的“常规”页管理自动保护、1–120 分钟时长、静音流检测和登录启动；“设备”页独立控制内建喇叭与外部设备名单。无法调节系统音量的设备不可勾选，断开的已选设备保留记录。刷新设备列表不主动重置等待时间。

关于页使用独立窗口，完整 MIT 协议单独查看；帮助与开源菜单提供文档、版本记录和 GitHub。

## v0.2.1 菜单信息

顶部依次显示小号品牌、主保护状态、设备名称和右侧音量百分比。长名称或错误摘要截断时，可悬停查看完整提示。故障状态隐藏百分比，避免把旧值作为有效状态。菜单打开时读取当前状态，打开期间没有新增自动倒计时刷新。其余操作、权限与设置含义不变。

## v0.2.2 留白修正

设备名称与右侧音量下方多余空白缩减 12pt。字体、原生菜单行为、设置与权限不变；无需重新配置。
