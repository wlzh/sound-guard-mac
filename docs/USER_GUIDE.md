# 使用指南

打开 Sound Guard.app 后点击菜单栏扬声器图标。默认保护内建扬声器，默认空闲 5 分钟归零。应用不会主动调高音量，若已归零，需使用系统音量键或控制中心手动打开。

## 两种检测模式

默认模式：音量大于 0 时监听系统输出播放活动；没有播放连续达到设定时长归零。播放器持续输出全零静音流也被当作播放，不会误关。

“静音流也计时”：在设置主动开启，额外检查数字音频。连续全零也会计时；微弱但非零声音不计为静音。需要 macOS 系统音频录制访问（具体权限名称随系统版本变化），不是麦克风权限，不保存录音。检测异常会停止保护并提示“重新核对”，不会偷偷退化为检测成功。

音量 0 或系统静音时，两种模式都停止播放检测。仅保留音量、路由与设备变更事件，以便你手动打开声音后恢复保护。不需要任何周期性扫描来等待你调高音量。

## 设备

内建扬声器默认勾选。耳机、蓝牙音箱、USB、显示器输出等默认不勾选，在“设置与设备选择”中选择。只对当前系统默认输出生效，既不切换输出，也不修改其他闲置设备。

设备按 UID 和路由保存，不靠同名推断。同名新设备、有线耳机插孔、路由变化可能需要重新选择。离线记录保留，取消勾选可移除。设备列表是设置窗口打开/刷新时的快照；插拔后可点击刷新。无法调节音量的设备明确标记不支持。

## 计时与操作

1. 设置 1–120 分钟整数后点击应用，当前空闲时间从头计算。
2. 播放开始、手动调节音量、切换设备、唤醒、恢复保护均取消旧计时。
3. “立即归零”只针对受保护的当前设备，即使在播放也可执行。
4. “暂停保护”不改动现有音量；退出也不恢复或修改音量。
5. 异常后点击“重新核对 / 重试”。静音流权限未允许时，可关闭进阶检测回到默认模式。

“登录时启动”默认关闭，仅你启用后注册；需要批准时到系统设置的登录项处理。

## 限制

不同软件可自行调大系统音量，本工具不是绝对防出声安全边界。默认模式依赖软件是否停止输出 IO；严格模式依赖系统真实音频回调，驱动异常产生的全零可能与真静音不可区分。重要场合请自己确认系统静音。

macOS 声音效果可能使用单独输出路由，首版不控制独立的系统声音效果输出或应用自选的非默认设备。Intel 和低版本系统包含构建支持但未等同实机验证。更多见 [测试](TESTING.md) 与 [性能](PERFORMANCE.md)。
