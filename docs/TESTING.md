# 测试状态与发布门禁

目标版本：0.1.0，预留 build 1。阶段：需求草案，未构建 App。

## 当前可运行检查

`zsh scripts/check-docs.sh` 检查版本基线、必要文档、28 项验收条目和明确的未实现状态。它不是功能测试。当前功能测试、构建、签名、实机、性能和 UI 验证均为 NOT RUN。

## 实现阶段必须补充

| 层级 | 覆盖范围 | 当前状态 |
| --- | --- | --- |
| 状态机单测 | 空闲阈值、播放恢复、归零后休眠、异常、设置边界、睡眠、设备变化 | NOT RUN |
| 注入集成测试 | 监听安装/释放、旧到期任务取消、读写失败、回读核验、不支持设备 | NOT RUN |
| App/UI | 菜单、设置、关于、登录启动、单实例 | NOT RUN |
| 实机功能 | 内建扬声器、耳机、麦克风单独使用、静音流、设备切换 | NOT RUN |
| 性能 | 0 音量/播放/空闲各 10 分钟，8 小时驻留，release RSS/CPU | NOT RUN |
| 分发 | 元数据一致、签名校验、ZIP、SHA256、安装卸载、私有 Release | NOT RUN |

测试应使用可控时钟，避免为了 5 分钟状态机用例真实等待。实机修改音量测试须明确告知用户，测试工具不得在结束后自动恢复非零音量。

发布门禁：需求与技术设计确认、统一自动化测试通过、28 项验收逐项填结果、性能数据达标或明确预览版限制、文档和版本一致后才能标记可用版本。没有 Apple Developer ID 和公证时仅标明 ad-hoc 签名，不称为已公证。
