# v0.2.0 界面设计

采用 macOS 原生 AppKit 语义色、系统字体与标准控件，保留明暗外观适应能力。图标为盾牌轮廓内的声波：声音与保护两个含义，不再与系统音量图标混淆。菜单栏使用 20pt 黑白模板，App 使用绿色圆角底图。

菜单顶部品牌、保护状态、当前设备三层信息，下方分为音量操作、设置和关于、帮助与退出。菜单只在打开时刷新。

设置窗口 580×650，常规/设备分段切换，分组卡片统一边距。标题、辅助说明、控件分层；禁用设备明确标识。关于窗口 440×520，参考 WatermarkFlow 和 Window Layout Memory：图标、标题、版本、作者与网站、项目链接、隐私与许可证。完整协议独立面板。
