# v0.3.3 产品需求文档

日期：2026-09-14。状态：开发预览。版本 0.3.3，build 8。

## 目标

恢复提示必须区分“用户已明确选择保持静音”和“用户暂时没有选择”。点击任一底部按钮完成本次恢复流程；左上角关闭或倒计时结束仅收起窗口，下一次真实播放开始仍可提示。按钮文案变长后继续保持相同尺寸、层级与对齐。

## 非目标

不自动恢复音量，不持久化恢复凭据，不把左上角关闭或超时解释为用户明确拒绝，不增加权限、音频 Tap、轮询器或后台定时器。
