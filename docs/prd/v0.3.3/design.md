# v0.3.3 界面设计

## 操作层级

恢复浮层延续 420×264pt 品牌面板。左侧次按钮为“保持静音，不再提醒”，右侧品牌主按钮为“恢复音量到 N%”。两者含义互斥，任一点击都完成本次选择；不使用只有上下文才看得懂的“继续”或“取消”。

两个按钮虽然字数不同，仍各使用 185×34pt 对齐矩形，间距 10pt，总宽 380pt，与信息卡边界一致。按钮文字居中，右按钮使用青绿色填充，均不绑定 Return，避免键盘误恢复。

倒计时显示“超时后关闭，下次播放仍提醒”。标题栏关闭按钮提示“暂时关闭；下次播放仍会提醒”，让临时关闭与明确保持静音在视觉和辅助功能语义上保持一致。

[深色预览](../../assets/v0.3.3/recovery-prompt-dark.png)和[浅色预览](../../assets/v0.3.3/recovery-prompt-light.png)由真实 AppKit 视图离屏生成；不是外部真实窗口、多屏位置或 VoiceOver 验收。
