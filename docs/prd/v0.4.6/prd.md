# v0.4.6 产品需求文档

2026-11-07，build 22，开发预览。本轮按用户需求把“恢复提示应用”例外的加入入口前移到恢复弹窗内：弹窗已显示触发来源，再提供一键“不再提醒”，免去打开设置逐个添加。不改变弹窗尺寸、保护行为或偏好格式。

## 背景证据

用户反馈：应用弹窗后，希望弹窗内显示是哪个应用/进程触发，并提供加入按钮，一键让该进程或 App 后续不再弹窗；同时要求界面不变大。现状：弹窗副标题已显示来源 App 名（`PlaybackScreenLocator.appName`），但加入例外需打开设置 → 恢复提示应用 → 从当前播放进程添加，路径长。

## 目标

弹窗内一键把触发来源加入例外名单：点击“不再提醒”即写入既有 `ignoredRecoveryApps`（按身份去重）、关闭本提示、音量保持 0，该 App 今后播放不再弹窗；设置中可移除。弹窗保持 420×350 与既有布局，不新增行高；无法识别来源时不显示链接。与“保持静音，不再提醒”（本设备本次守望）语义并存、互不影响。
