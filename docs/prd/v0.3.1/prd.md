# v0.3.1 产品需求文档

日期：2026-09-14。状态：开发预览。版本 0.3.1，build 6。

## 问题

v0.3.0 在严格静音流模式自动归零后改用进程输出标志等待恢复。持续输出全零样本的播放器仍被 Core Audio 标记为运行输出，导致用户没有开始新播放也立即看到恢复提示。

## 目标

严格模式必须依据真实非零输出信号提示，默认模式仍保持无音频采样的低资源事件机制。修正不得自动恢复音量、重复申请权限或破坏归零结果。

## 非目标

不自动调高音量，不识别媒体语义，不恢复单个 App 音量，不把辅助功能用于音频判断。A34 未完成前继续标记为开发预览。
