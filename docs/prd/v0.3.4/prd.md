# v0.3.4 产品需求文档

日期：2026-09-15。状态：开发预览。版本 0.3.4，build 9。

## 目标

声音守卫自动归零后，不应因瞬时播放活动立即显示恢复提示。用户可独立设置播放需要持续多久才算有效，默认 2 秒，范围 500 毫秒至 30 秒；该设置不得增加常驻监听或改变自动归零和弹窗停留行为。

## 验收

- [x] A01 新增独立有声确认偏好。
- [x] A02 默认有声确认时长为 2 秒。
- [x] A03 最小值为 500 毫秒。
- [x] A04 最大值为 30 秒。
- [x] A05 越界持久化值回退到 2 秒。
- [x] A06 旧偏好缺少字段时迁移为 2 秒。
- [x] A07 偏好 JSON 往返保留毫秒值。
- [x] A08 设置页显示有声确认独立行。
- [x] A09 默认显示为 2 秒。
- [x] A10 设置支持毫秒单位。
- [x] A11 设置支持秒单位。
- [x] A12 秒单位支持 0.5 等小数输入。
- [x] A13 设置拒绝小于 500 毫秒。
- [x] A14 设置拒绝大于 30 秒。
- [x] A15 提示停留时长保持独立。
- [x] A16 默认模式播放开始后不立即提示。
- [x] A17 默认模式持续到截止时间才提示。
- [x] A18 默认模式只使用单次截止任务。
- [x] A19 默认模式不增加周期轮询。
- [x] A20 严格模式复用已有 Signal Tap。
- [x] A21 严格模式检查频率保持 0.5 秒。
- [x] A22 严格模式不申请新增权限。
- [x] A23 播放停止清除未完成确认。
- [x] A24 再次播放从零重新确认。
- [x] A25 确认时长改变后从零重新确认。
- [x] A26 取消任务的旧回调不能弹窗。
- [x] A27 短于 600 毫秒的严格静音仍连续。
- [x] A28 达到 600 毫秒静音可形成新播放沿。
- [x] A29 同一段连续播放仍只提示一次。
- [x] A30 显式按钮选择仍消费恢复凭据。
- [x] A31 左上角关闭和超时语义不变。
- [x] A32 状态可区分等待播放与正在确认。
- [x] A33 版本、文档、性能与测试同步。
- [ ] A34 真实播放器与严格模式完成实机确认时长验收。

## 非目标

不改变“任何有限非零采样即有声”的既有严格检测边界，不引入分贝阈值，不增加新的音频 Tap、辅助进程、网络请求或后台高频轮询，不自动恢复音量。
