# v0.3.4 界面设计

## 设置位置

“有声确认”位于“音量恢复提醒”分组，排在恢复开关和“提示停留”之间。辅助说明为“持续 500 毫秒至 30 秒才提示；默认 2 秒”，清楚区分弹窗出现前确认与弹窗出现后的停留倒计时。

输入控件沿用现有紧凑布局：48pt 居中文本框、单位下拉框和“应用”按钮。单位提供“毫秒”和“秒”；默认显示 `2 秒`，非整秒保存值使用毫秒显示。用户也可输入 `0.5 秒`，保存后规范化为 `500 毫秒`。

恢复浮层本身不增加控件或说明，避免扩大窗口和干扰恢复选择。正在确认仅反映在菜单状态和只读诊断中，不增加持续动画。
