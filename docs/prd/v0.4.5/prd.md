# v0.4.5 产品需求文档

2026-11-06，build 21，开发预览。本轮修复一个用户实机反馈的 UI 缺陷：菜单栏图标悬停提示（如“声音守卫：音量为 0，等待新的播放活动”）经常跟着光标跑很远。根因是提示显示期间状态刷新重新赋值属性式工具提示，系统帮助标签失去归属。不改变保护行为、文案口径、权限或偏好格式。

## 背景证据

用户反馈：悬停菜单栏图标查看状态时，提示“经常跟着跑很远”。代码证据：`updateStatus` 在每次状态刷新时无条件赋值 `status.button.toolTip`；触发源为 30 秒心跳、系统音频事件回调与恢复确认计时。零音量守望（v0.4.4）使“等待新的播放活动”状态长期驻留，悬停窗口与刷新相交概率大增；AppKit 对属性式 toolTip 的赋值会移除并重挂标签注册，发生在标签显示中即出现跟随光标。

## 目标

悬停提示在任何刷新节奏下都保持“鼠标离开即消失”的归属；提示内容在每次显示时反映当前状态；VoiceOver 帮助文案保持实时同步。保护、恢复、守望、诊断、偏好与全部界面文案零变化。
