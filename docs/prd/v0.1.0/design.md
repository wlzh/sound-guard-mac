# v0.1.0 界面设计

原生菜单栏工具，不显示 Dock 图标。不采用常驻主窗口、仪表盘、波形动画或每秒倒计时。

## 菜单

从上到下：名称与版本、保护状态、当前输出/音量、最近一次动作、暂停/恢复、立即归零、重新核对、设置、关于、使用说明、退出。状态说明包含零音量休眠、播放中、空闲等待、未选设备、不支持和异常。

立即归零只对已允许的可控当前设备启用。它是明确的手动操作，允许在播放时执行。退出不改变音量。

## 设置

540 × 630 的可滚动原生窗口。顺序：启用保护、空闲分钟输入及应用按钮、静音流开关与解释、设备选择、刷新、登录启动。1–120 以外的输入提示错误，不保存。

内建扬声器独立复选框；其他在线输出按名称逐项勾选，不支持软件音量控制的设备标明原因。离线已选设备显示离线/路由变化，可取消删除。设备列表由用户刷新；后台不为了列表动画频繁刷新。

启用静音流模式先说明将读取系统音频信号，且无麦克风、无保存上传，确认后才开启。当前音量 0 时仍不采样；以后非零时才创建检测。系统权限拒绝后显示异常，不静默假装已检测。

## 关于与可访问性

540 × 450 原生窗口包含中英文名称、0.1.0/build 1、开发预览提示、版权、作者、网站、GitHub、离线文档及可选择复制的完整 MIT 协议。关闭不退出服务。

使用系统原生文字、复选框、焦点顺序和浅/深色适配；提示不用单一颜色表达。菜单图标提供可访问名称。窗口内容允许选择/滚动，无后台动画。
