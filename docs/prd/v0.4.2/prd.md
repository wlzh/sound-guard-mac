# v0.4.2 产品需求文档

2026-10-25，build 18，开发预览。本轮针对全链路审计发现的可靠性和交付一致性缺口，不改变默认功能或增加权限。

## 目标

安全取消不应导致保护永久停机；读取故障与已发生的写入失败应区别处理。恢复凭据失效后及时清理资源，健康运行可恢复有限重试预算。文档及本地发行包必须可验证，自动化与实机结论分开记录。

## 验收

- [x] A01 归零前播放恢复只取消操作，不锁定写入故障。
- [x] A02 归零前设备变化只取消操作。
- [x] A03 归零前音量变化后重新给予完整空闲时长。
- [x] A04 写入前读取临时失败允许有限重试。
- [x] A05 已开始归零写入后的错误不自动重试。
- [x] A06 已开始恢复写入后的错误继续安全锁定。
