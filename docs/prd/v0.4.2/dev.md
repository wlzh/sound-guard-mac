# v0.4.2 技术设计

## 状态与错误边界

`AudioOperationFailure.cancelled` 表示尚未写入的预期安全取消；`preflight(Error)` 包装适配层写前读取故障。`SystemAudio.zero/restore` 仅将写前阶段包装为此类型，首个 HAL 写入开始后不包装，继续进入控制器写故障锁。控制器对取消重新读取状态，对写前故障沿用原有错误分类和 3/10/30 秒有限退避。

归零快照增加有限值、通道非空和最大值一致性校验。写后设备 ID、selectionID、静音状态均参与复核；恢复仍逐通道校验，并在失败时尽力归零。系统检查与写入不是原子事务，不能消除全部外部竞态。

`zeroNow` 区分读设备、释放监听和写入阶段；冷却期间直接返回。恢复确认的设备校验失败或适配层取消立即撤销记录并刷新，释放监听并更新 UI。短暂写前读取失败按原规则保留恢复上下文；实际写入失败仍消费上下文且锁定。

`fail` 在清空健康时间前结算已满 60 秒的健康预算；例外播放分支调用 `markHealthy`。`start` 清理旧检测故障和重试状态，保留写入故障。未新增定时器或轮询。

## 信号与身份

C 摘要扫描完整缓冲区，记录是否存在非零信号，避免首个有声样本导致后续 NaN/Infinity 漏检；实时回调仍不分配内存。父路径必须以 `.app` 结尾才允许 Contents 嵌套匹配。

## 上下游影响

偏好 Codable 格式、设备名单、恢复提示模型和 CLI 参数不变。新增公开错误枚举供平台和注入服务使用；其他 AudioService 实现只应在确知未发生写入时使用它。菜单增加冷却禁用，应用选择弹窗复用品牌提示工厂。

发行构建在独立暂存目录构造 App，验证后替换 `dist`，避免遗留资源；失败保留原构建。打包在任何构建前检查同版本归档，执行 ZIP 自检并保存版本专用 SHA256。CI 改为运行完整打包门禁，远端执行结果必须另验。

文档门禁核对当前入口版本、顺序完整的验收编号、每个测试的唯一注册及当前报告总数。审计记录集中描述真实缺口，历史版本材料只作历史记录。
