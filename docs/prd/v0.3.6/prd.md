# v0.3.6 产品需求文档

2026-09-18，版本 0.3.6 / build 11，开发预览。

## 目标

开启静音流检测时，没有任何播放也能正常进入空闲计时，达到时长自动归零。重新核对不应因无播放而进入永久故障。检查结果必须区分检测对象存在与有效音频样本到达，不能以启动成功冒充实机验收。
