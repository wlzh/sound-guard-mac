# v0.3.8 界面设计

恢复浮层为 420×350pt，保留品牌图标、播放来源、青绿确认按钮与原生明暗外观。音量卡片显示设备、24pt 等宽数字选中值、全宽滑块、1%/100% 边界，以及“归零前 N% / 还原”辅助行。卡片下是确认后生效说明和倒计时。

底部仍为两个 185×34pt 按钮，间距 10pt：“保持静音，不再提醒”和“恢复到 N%”。不将恢复按钮绑定 Return。还原在默认状态禁用；极小原值显示 <1%，不误导为 0%。

拖动只选择，确认才出声；拖动期间冻结剩余秒数，松手继续。新提示回到原值。关闭和超时不消费恢复记录，底部按钮消费记录；设备/音量变化仍使旧提示失效。
