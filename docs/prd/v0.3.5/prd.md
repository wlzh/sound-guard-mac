# v0.3.5 产品需求文档

日期：2026-09-18。状态：开发预览。版本 0.3.5，build 10。

## 目标

手动“重新核对”不得在销毁严格 Signal Tap 后立即竞争式重建。系统应先完整释放检测，等待固定冷却时间，再只重建一次；用户必须看见过程状态，自动保护在成功重建后恢复，失败则继续明确锁存而不静默降级。

## 非目标

不改变静音流信号判定、自动归零条件、恢复音量安全复核或权限策略；不在严格检测失败时宣称默认检测仍等价有效；不自动调高系统音量。
