# v0.3.0 产品需求文档

日期：2026-09-14。状态：开发预览。版本 0.3.0，build 5。

## 目标

声音守卫自动归零后，如果用户再次启动播放，在合适的显示器提示是否恢复本次归零前的系统输出音量。默认行为继续保持单向归零；只有用户开启功能并对当次弹窗明确点击恢复，才允许提高音量。

## 范围与默认值

- 恢复提醒默认关闭；空闲归零默认 5 分钟及设备选择规则不变。
- 仅空闲超时造成的自动归零建立恢复凭据；菜单立即归零、系统手动归零不建立。
- 提示默认 60 秒，允许 5–600 秒，可按秒或分钟输入。
- 辅助功能仅定位播放窗口所在显示器；关闭功能不申请，拒绝后回退鼠标所在显示器。
- 恢复的是当前默认输出设备的系统音量，可能同时影响多个播放 App，不提供单 App 音量控制。
- 恢复凭据仅在进程内存存在，不跨退出、升级、睡眠或设备变化保存。

## 功能要求

| 编号 | 优先级 | 要求 |
| --- | --- | --- |
| F01 | P0 | 自动归零前保存设备标识、路由、静音状态及各音量控制通道原值 |
| F02 | P0 | 归零成功后才进入恢复等待；失败或手动归零不得进入 |
| F03 | P0 | 恢复等待只使用播放事件，不启动音频样本分析或麦克风 |
| F04 | P0 | 新播放开始沿提示一次；连续播放不重复，停止后下一次可再提示 |
| F05 | P0 | 只有恢复按钮能写入非零值；取消、关闭、超时、失效均保持 0 |
| F06 | P0 | 恢复前复核默认设备、ID、UID、路由、音量 0 和静音状态 |
| F07 | P0 | 多通道逐通道恢复；写入或复核失败尽量全部回滚到 0 |
| F08 | P1 | 通过播放 PID 识别 App 与活动窗口，弹在对应显示器右上角 |
| F09 | P1 | 定位失败或权限拒绝时回退鼠标屏幕，不影响归零保护 |
| F10 | P1 | 面板不抢焦点、不发声音、按钮不绑定 Return，视觉与 App 一致 |
| F11 | P1 | 设置和菜单均展示总开关，设置提供秒/分钟倒计时及权限状态 |
| F12 | P1 | 状态诊断区分空闲保护监听与恢复事件监听 |

## 验收清单

- [x] A01 新安装和旧设置迁移后恢复提醒均默认关闭。
- [x] A02 旧设置中的启用、时长、检测模式和设备名单不丢失。
- [x] A03 提示默认 60 秒，合法范围 5–600 秒，非法持久值回退 60 秒。
- [x] A04 自动归零成功后保存当次各音量通道原值。
- [x] A05 归零失败不建立恢复凭据。
- [x] A06 菜单立即归零不建立恢复凭据。
- [x] A07 非本 App 造成的零音量不建立恢复凭据。
- [x] A08 功能关闭时零音量没有播放进程监听或倒计时。
- [x] A09 功能开启且自动归零后仅保留 Core Audio 播放事件监听。
- [x] A10 恢复等待不启动 Signal Tap，不采集麦克风或保存音频。
- [x] A11 播放从无到有时生成一次恢复提示。
- [x] A12 同一段连续播放的重复系统事件不重复提示。
- [x] A13 播放停止后再次开始可重新提示。
- [x] A14 提示显示播放 App、设备、原音量和剩余秒数。
- [x] A15 “保持静音”、关闭窗口和倒计时结束均不写音量。
- [x] A16 恢复按钮不绑定 Return 或其他隐式确认快捷键。
- [x] A17 点击恢复前再次核对当前默认设备及稳定设备身份。
- [x] A18 点击恢复前再次核对路由、音量仍为 0、静音状态未变。
- [x] A19 设备、路由、音量、静音、睡眠或设置变化使旧请求失效。
- [x] A20 多通道快照保留每个控制通道值，展示值使用可见最大值。
- [x] A21 多通道数量变化时拒绝恢复。
- [x] A22 恢复部分写入失败时尝试将所有通道重新归零。
- [x] A23 恢复后逐通道回读；不一致时尝试归零并报告失败。
- [x] A24 辅助恢复监听注册失败不改变已成功归零的主状态。
- [x] A25 关闭恢复提醒或自动保护立即释放恢复凭据和监听。
- [x] A26 退出 App 不持久化恢复凭据且不恢复音量。
- [x] A27 功能关闭时不调用辅助功能授权请求，权限按钮禁用并说明原因。
- [x] A28 首次开启先说明用途，再请求辅助功能；拒绝仍保存功能开关。
- [x] A29 有权限时优先使用播放 App 活动窗口所在显示器。
- [x] A30 浏览器辅助进程尽量映射到外层普通 App。
- [x] A31 无权限、PID 或窗口时回退鼠标所在显示器。
- [x] A32 提示为非激活浮动 NSPanel，使用品牌图标、原生语义色和分组卡片。
- [x] A33 状态导出包含 recoveryMonitoringActive，菜单与设置状态一致。
- [ ] A34 在允许/拒绝辅助功能、多显示器、主流播放器和外部设备上完成真实端到端及长期性能验收。

## 非目标和限制

不自动恢复、不恢复单个 App 音量、不跨重启记忆、不保证浏览器具体标签页或跨 Space 窗口精确定位。默认事件模式可能把持续数字静音流视为播放并提示；这不会自动出声。未完成 A34 前保持开发预览。
