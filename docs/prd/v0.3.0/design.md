# v0.3.0 界面设计

## 设置

常规页新增“音量恢复提醒”分组，与既有圆角卡片、语义色和间距一致。包含总开关、提示停留时长和定位播放窗口三行。时长支持数值加“秒/分钟”原生下拉框；功能关闭时权限按钮禁用，文字明确“不申请辅助功能权限”。开启时先显示用途确认，再触发系统授权提示。

## 恢复面板

面板固定 400×224pt，位于目标显示器可见区域右上角 18pt。使用 32pt 绿色盾牌声波图标、15pt 主标题、12pt App 名；中部沿用设置页圆角卡片，展示设备和 18pt 原音量。底部显示倒计时，按钮按“保持静音”“恢复至 N%”排列。

使用非激活浮动 NSPanel，不播放提示音，不抢当前 App 焦点。两个按钮都没有默认 Return 快捷键。关闭按钮等价于保持静音。明暗外观使用 AppKit 语义色，不硬编码效果图背景。

## 可访问性和定位

控件使用明确的中文可访问名称。恢复按钮说明目标百分比；窗口不会通过回车误触。播放进程可能是浏览器 Helper，先映射到外层普通 App，再通过 AX focused/main window 获取边界，与 Core Graphics 显示器边界求最大交集。失败回退鼠标所在显示器。
