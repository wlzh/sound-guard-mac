# v0.3.2 界面设计

## 图标规则

菜单栏使用单色模板盾牌声波；设置、关于、恢复浮层和所有自建 Alert 使用彩色 AppIcon。`UI.alert` 是静音流确认、恢复功能确认、错误和许可证提示的唯一构造入口，避免系统默认图标和缓存差异。

## 恢复浮层

面板固定 420×264pt，外边距 20pt。顶部使用 42pt 彩色图标，右侧依次为 11pt 场景标签、17pt 主问题和 12pt 播放来源。中间 380pt 宽卡片显示设备与 24pt 等宽音量；其下显示剩余时间及超时结果。

底部两个按钮各使用 185×34pt 对齐矩形，间距 10pt，总宽 380pt，与信息卡边界一致。左侧为系统次按钮“继续静音”，右侧为品牌青绿色主按钮“恢复到 N%”。恢复操作有明确文案但没有 Return 默认键；关闭按钮等同继续静音。
