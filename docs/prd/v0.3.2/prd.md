# v0.3.2 产品需求文档

日期：2026-09-14。状态：开发预览。版本 0.3.2，build 7。

## 目标

所有声音守卫自建提示窗口必须使用一致品牌图标；恢复声音浮层需要清晰表达发生了什么、来自哪个 App、将恢复哪个设备与音量、剩余时间及两个互斥操作。

## 非目标

不改动音频状态机，不添加动画或后台 UI 刷新，不把恢复按钮设为默认回车操作，不声称离屏预览等同实机可访问性验收。
