# v0.4.4 产品需求文档

2026-11-05，build 20，开发预览。本轮针对一次实机诊断证实的“音量为 0、检测已休眠”死角：恢复记录被作废且设备停在音量 0 时，守卫既不弹恢复提示、也无法再次自动归零（归零需要音量大于 0），保护静默失效直到用户手动调高音量。不改变权限、默认功能或音量安全边界。

## 背景证据

2026-11-05 诊断日志：17:52:53 自动归零并武装恢复监测；18:16:01 恢复记录以“输出设备、路由、音量或静音状态已变化”作废（该机存在显示器音频与多个虚拟声卡，路由抖动常见）；此后系统音量保持 0，状态导出 monitorActive=false、playbackListeners=0、signalActive=false，19 时新播放活动无弹窗。历史上 10-29 至 11-05 共 9 次 recoveryInvalidated 事件，每次都进入同一死角。

## 目标

音量 0 不再等于保护休眠：恢复提醒开启且设备受保护、未静音、音量为 0、未被确认保持静音时，自动守望新的播放活动并按既有有声确认与例外规则弹窗。守望凭据可跨记录失效、睡眠唤醒、检测重建与应用重启自动重建。用户显式选择（保持静音、手动归零）仍优先：抑制守望直到该设备音量离开 0。恢复建议音量诚实：优先沿用记忆中的上次非零音量，未记录时明确标注建议值。

- [x] A01 恢复记录因设备、路由、音量或静音变化作废且设备停在音量 0 时，下一个刷新周期自动重新武装播放守望。
- [x] A02 零音量守望凭据与自动归零凭据走同一恢复链路：有声确认、例外名单、同段去重、弹窗与超时行为完全一致。
- [x] A03 睡眠唤醒、检测自动重建、写入故障恢复、应用重启后停在音量 0 时同样自动重新武装守望。
- [x] A04 守望凭据同样被设备、路由、非零音量与静音变化作废；音量离开 0 回到常规空闲保护。
- [x] A05 “保持静音，不再提醒”后该设备在音量 0 期间不再守望、不再弹窗。
- [x] A06 菜单“立即归零”同样抑制守望，直到该设备音量离开 0；抑制不跨设备传播。
- [x] A07 音量离开 0（调高）即解除抑制并恢复常规保护与空闲计时。
