# v0.4.4 界面设计

保留现有原生 AppKit 视觉、菜单结构、设置页与恢复浮层，不新增窗口或权限提示。

零音量守望不新增界面元素：状态栏工具提示与菜单头部在“音量为 0”下区分三种子状态——守望中（“音量为 0，等待新的播放活动”）、已确认保持静音（“音量为 0，不再提醒新的播放”）与检测已休眠（恢复提醒关闭等）。守望中的确认新播放子状态文案不变。

恢复浮层新增一种“未记录原音量”呈现：音量卡片下沿的“归零前 X%”替换为“未记录归零前音量，建议 X%”，滑块默认停在建议值（25%），仍可 1–100% 调整；两个底部按钮、等宽布局、无默认回车与拖动不出声语义全部不变。设置页“播放时提示恢复”的说明与开启确认文案同步说明零音量守望、建议音量与抑制规则。
