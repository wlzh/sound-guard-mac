# v0.2.2 界面设计

将已确认效果图落实为 AppKit 原生布局，而非把生成图片贴入界面。固定宽 316pt、高 72pt；左右边距 14pt，顶部 10pt，行距 5pt。品牌 12pt medium 搭配 14pt 模板图标；主状态 14pt medium；设备和音量 12pt 次级色，音量使用等宽数字并右对齐。长文本单行尾部截断，完整文字保留为 tooltip 与辅助功能标签。

保留系统菜单行、分隔线、勾选及快捷键样式。使用语义颜色自动适配明暗外观，不强制效果图的材质或像素外观。

[深色头部](../../assets/v0.2.2/menu-header-dark.png)、[浅色头部](../../assets/v0.2.2/menu-header-light.png)。原生离屏渲染，不等同系统菜单截图。

## 本版本范围

根据用户红框仅收紧设备行下方空白：固定头部由 84pt 减为 72pt。文字位置、字体和原生菜单不变，不改成自定义面板。上游状态、下游命令与音频逻辑不变。新增末行底部留白 0–8pt 的明暗布局断言。
