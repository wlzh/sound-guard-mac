# v0.3.7 产品需求文档

2026-09-18，0.3.7 / build 12，开发预览。

## 目标

自动归零后重新核对不应遗忘原音量，后续有效播放仍可由用户确认恢复。重试必须保留安全边界、不重复提醒、不把启动等待误判为播放。
