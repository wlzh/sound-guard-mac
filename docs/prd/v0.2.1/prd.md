# v0.2.1 产品需求文档

项目名称：Sound Guard / 声音守卫。负责人：wlzh。日期：2026-09-10。

状态：按用户确认实现开发预览。版本 0.2.1，build 3。勾选框保留为实机验收，不把模拟测试等同实机验收。

## 目标与用户故事

用户手动开启扬声器后，可能忘记关小音量，之后启动软件突然出声。应用应在输出长时间不使用时把系统音量归零，且不替用户重新打开声音。

作为用户，我希望保护自动工作、不干扰正在播放的内容、不依赖麦克风，同时尽可能少占 CPU、内存和电量。是否重新开启声音由我在系统中手动决定。

成功指标：全部 P0 验收通过；零自动提高音量路径；零音频存储和上传；零音量驻留状态无播放检测与周期计时；性能门禁有实测证据后才可宣称达标。

## 定义与首版边界

- “声音输入”在本项目中解释为送往输出设备的播放活动，不是麦克风输入或周围环境音。
- “输出设备”指当前系统默认输出设备。默认仅保护系统内建扬声器；其他耳机、蓝牙/USB 音箱逐项勾选。白名单只授权当前默认输出，不修改闲置设备，不控制单个应用音量。
- “归零”指将输出音量数值设为 0，不只是按静音键。恢复播放不解除归零。
- 默认低开销模式：无输出播放活动持续到达设定时长才归零，有活动但样本全为 0 的静音流视为使用中。
- “静音流也计时”开关默认关闭，开启后需系统音频信号检测，只有数字全零算静音，任何非零音频都中断空闲。读取不到有效回调不算静音。此模式有额外资源开销及权限需求。
- 首版不包含麦克风控制、均衡器、音频录制、音量自动恢复、云同步或全局快捷键。

## 行为细节

首次启动已有非零音量且没有播放时，从启动核对成功开始计时，不根据启动前未知历史立即关闭。暂停后恢复保护同理。手动改变非零音量被视为用户操作，给予新的完整等待时间。修改超时时长也从当前状态重新开始计时，避免刚设置就意外归零。

系统静音但音量数值仍非零时，暂停保护检测；不为了数值整齐强制写入音量。用户取消静音后按当前状态重新检测。归零写入后需回读核验；失败显示实际状态，不显示虚假的成功。

倒计时不要求每秒刷新。菜单打开时显示状态快照即可，不能为了动画增加后台周期唤醒。后台无需常驻设置窗口或提醒弹窗。

## 验收清单

- [ ] A01 默认超时值为 5 分钟，首次启动已有空闲输出不会立即归零。
- [ ] A02 非零音量、无播放连续达到阈值后输出音量数值为 0。
- [ ] A03 连续播放超过阈值不归零。
- [ ] A04 倒计时中恢复播放，旧任务到期不归零。
- [ ] A05 播放再次结束，重新获得完整空闲时间。
- [ ] A06 音量为 0 时没有播放监听、音频采样或空闲计时任务。
- [ ] A07 手动调高音量后保护自动恢复，但不擅自改回旧音量。
- [ ] A08 从归零状态开始播放，音量保持为 0。
- [ ] A09 手动调整非零音量后完整重新计时。
- [ ] A10 静音/取消静音符合上述策略，不自动取消静音。
- [ ] A11 设备切换不执行旧设备的到期写入。
- [ ] A12 耳机连接、断开后对新默认设备重新开始计时。
- [ ] A13 睡眠期间不累计到期归零，唤醒后重新核对。
- [ ] A14 系统服务重启或状态读取失败不视为无播放。
- [ ] A15 不支持音量控制时显示不支持，音量未被误报为 0。
- [ ] A16 写入失败/回读不为 0 时不报告成功，不连续重试写入。

- [ ] A21 麦克风单独录音不被误认为扬声器播放。

- [ ] A26 无网络连接需求、无麦克风权限请求、无音频文件产生。

- [ ] A29 静音流开关默认关闭，开启前说明权限，关闭后释放信号检测。

## 非功能要求

性能目标而非当前实测结论：release 构建在指定测试 Mac 上零音量驻留 10 分钟，平均进程 CPU 不超过 0.1%，RSS 不超过 30 MiB；播放/空闲计时各 10 分钟平均 CPU 不超过 0.5%；8 小时驻留无持续内存增长，后 1 小时与首个稳定小时平均 RSS 差不超过 5 MiB。报告必须注明测量工具和采样自身的扰动。

后台不进行周期性全系统扫描、不保留音频缓冲、不运行 WebView/浏览器内核。零音量时仍需保留必要的音量和设备变化通知，因此“关闭检测”不代表退出进程、零内存或绝对零 CPU。

拟定最低 macOS 14.2，最终支持版本和架构在技术设计及实机验证后确认。内建输出先验收，再分别记录蓝牙、USB、HDMI 的支持与限制。不宣称未测设备受支持。

隐私：所有偏好本地保存，不上传音频、设备信息或操作历史。不将应用当作阻止任何意外出声的绝对安全保证。

## 已确认决策

默认不把静音流计入空闲，可选开启；默认仅内建扬声器，其他设备列表勾选。严格模式最低样本幅度不设噪声门，避免关闭仍有微弱声音的播放。首版优先保守不误关，异常需用户点击重新核对。
