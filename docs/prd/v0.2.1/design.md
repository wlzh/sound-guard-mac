# v0.2.1 界面设计

将已确认效果图落实为 AppKit 原生布局，而非把生成图片贴入界面。固定宽 316pt、高 84pt；左右边距 14pt，顶部 10pt，行距 5pt。品牌 12pt medium 搭配 14pt 模板图标；主状态 14pt medium；设备和音量 12pt 次级色，音量使用等宽数字并右对齐。长文本单行尾部截断，完整文字保留为 tooltip 与辅助功能标签。

保留系统菜单行、分隔线、勾选及快捷键样式。使用语义颜色自动适配明暗外观，不强制效果图的材质或像素外观。
