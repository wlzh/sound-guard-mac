# v0.1.0 发行说明

Sound Guard / 声音守卫，build 1，首个开发预览。

新增播放空闲单向归零、默认 5 分钟、可选静音流检测、默认内建扬声器与外部设备白名单、暂停/重试/手动归零、登录启动、关于和离线文档。默认模式不请求系统音频内容访问，零音量时释放播放检测。

提供 Universal ZIP 和 SHA256，ad-hoc 签名、未公证，仓库及 Release 私有。请阅读 [安装](../INSTALL.md)、[使用指南](../USER_GUIDE.md) 和 [测试状态](../TESTING.md)。

已通过 48 项自动化回归及内建扬声器 1 分钟实机归零与检测释放；GUI 默认参数仍为 5 分钟。首个 GUI 5 分钟观察未成功归零，原因未独立定位，已记录在测试报告，不能将短时通过视为稳定性结论。

未完成的正式验收：权限允许/拒绝矩阵、外接蓝牙/USB/HDMI、睡眠/音频服务重启、Intel/最低系统版本、10 分钟各运行状态及 8 小时驻留。自动化结果不替代这些实机证据，因此发布为预览而非稳定版。
