# v0.3.9 / build 15

临时检测故障不再一律锁死。音频对象失效、暂未就绪、回调中断等按 3/10/30 秒最多三次自动重建；持续健康观察 60 秒恢复预算。权限、格式及音量写入异常保守锁定。自动重建只恢复检测，不提高系统音量，不把故障期间算为空闲。

保留合法原音量与同段去重，重建后重新核对设备和音量；睡眠、退出、设置变化撤销旧任务。原有滑块恢复确认和测试偏好隔离保留。

新增本机最近 64 条诊断记录，菜单“帮助与开源 → 显示诊断文件…”及 --diagnostics 可查看。无音频、设备 UID 或播放 App 信息，不上传。重新核对不会抹去上一次故障。
