# v0.3.0 / build 5

新增默认关闭的“播放时提示恢复”。声音守卫因空闲自动归零后，可在检测到下一次播放时显示非激活确认面板；默认 60 秒，可设 5–600 秒。保持静音、关闭和超时不写音量，只有点击“恢复至 N%”才恢复。

恢复凭据保存设备、稳定路由、静音状态和各音量通道原值，仅存在内存。恢复前再次核对；设备或音量变化立即失效。多通道按原值恢复，写入或复核失败尽量回滚到 0。菜单立即归零不触发此功能。

辅助功能仅用于定位播放 App 的窗口和显示器。功能关闭时不请求；开启时先解释再请求；拒绝后回退到鼠标所在屏幕，归零功能不受影响。恢复等待使用 Core Audio 播放事件，不使用麦克风或 Signal Tap。

自动化覆盖设置迁移、播放沿、去重、失效、恢复复核、辅助失败隔离、设置和恢复面板明暗 UI。真实确认恢复、多显示器、辅助功能权限、外部设备和长期性能仍需实机验收，因此继续标记开发预览。
