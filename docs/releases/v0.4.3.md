# v0.4.3 / build 19

2026-11-05，开发预览。

- 检测故障不再永久停机：锁定的检测故障由 30 秒心跳看门狗自动重建，等效自动"重新核对"，无需人工干预；写入故障锁仍要求人工核对。
- 'who?'（OSStatus 2003332927）归类为临时错误；该错误来自设备切换瞬间读取已消失的默认设备对象，是 2026-10-31 与 11-04 两次长时间停机的直接原因。
- 默认设备读取遇到临时失效时重读一次默认设备，路由切换竞态多数情况下无感恢复，不进入故障态。
- 新增 30 秒周期复核，系统通知静默丢失时也能发现音量回升、播放停止等变化；空闲截止与恢复确认时间保持不变。
- 持续故障诊断节流（首次与每 20 次重建留痕），状态导出新增 sustainedFault 与 automaticRecoveryArmed；菜单提示"将自动重试"。
- 新增 5 项注入回归，合计 123 项 / 610 次断言。

自动化不提高真实系统音量，不自动恢复音量。偏好格式不变，无新增权限、音频采集或网络功能。真实设备切换、播放器/多屏/外设/权限/长时性能以及远端发布结果见[测试报告](../TESTING.md)，不以本地构建冒充安装或公开发行。
