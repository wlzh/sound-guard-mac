# v0.4.1 / build 17

2026-10-19，开发预览。

## 改动

- 加入外层 App 后，可覆盖其 `Contents` 内独立运行的子 `.app`，包括 MuMu 主程序与“MuMu安卓设备”。
- 新增“从正在运行的应用添加…”，应用不必正在出声；选择项显示名称和稳定身份。
- 嵌套匹配限制在真实 App 包边界，不使用 PID、名称或宽泛路径前缀。

## 安全边界

例外仍只抑制自动归零后的恢复提示，不阻止播放、不影响自动归零或恢复前复核。混合播放、未知来源及严格模式无进程身份时继续提示。不新增权限、音频保存、上传或后台服务。

## 验证范围

自动化覆盖父子 App、相似路径、普通 helper 和原生 UI 入口。Universal arm64/x86_64 构建及 ad-hoc 签名纳入发布门禁。真实 MuMu 播放、多屏、外设与长期运行由人工继续验收。
