# v0.3.5 / build 10

更正：本版实机复测失败，未完成问题修复；以下是当时方案说明，不是最终根因。请使用 v0.3.6 的配置修正。

修复开启“静音流也计时”时点击“重新核对”可能永久停在“保护需要检查”、随后无法自动归零的问题。原因是旧 Signal Tap 刚销毁便立即重建，Core Audio 资源尚未释放，新检测实例可能收不到启动回调。

重新核对现在先停止检测并等待 3 秒，再只重建一次。等待期间菜单明确显示“正在重新核对”并禁用重复操作；设备事件和设置刷新不会提前重建，退出或睡眠会取消旧任务。失败仍明确提示，不静默降级；正常检测、权限和自动归零条件不变。
